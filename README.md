# Calculadora de Holerite

Aplicação web desenvolvida para realizar cálculos automáticos de salário líquido com base em descontos trabalhistas.

O projeto foi criado com foco em praticar lógica de programação, manipulação de dados e desenvolvimento web com JavaScript.

---

## Tecnologias utilizadas

- HTML
- CSS
- JavaScript

---

## Funcionalidades

- Cálculo de salário líquido
- Cálculo automático de descontos
- Interface simples e intuitiva
- Entrada de dados pelo usuário
- Exibição dinâmica dos resultados

---

## Objetivo do projeto

Conceitos aplicados:

- Lógica de programação
- Manipulação de variáveis
- Cálculos matemáticos
- Interação com o DOM
- Desenvolvimento de interfaces web
